### Цель работы

Изучить механизм сигналов и слотов PyQt5 на примере приложения с взаимосвязанными полями ввода.

### Описание программы

Разработан конвертер валют с тремя полями: **доллар США (USD)**, **российский рубль (RUB)** и **евро (EUR)**. Пользователь может вводить сумму в любом из полей, два остальных автоматически пересчитываются. Присутствует кнопка сброса значений.

Для наглядности используется следующий курс валют:

- 1 USD = 82 RUB;
- 1 EUR = 1.10 USD.

### Основные компоненты

- `QLineEdit.textEdited` передаёт изменённый текст из поля ввода.
- `CurrencyField.edited = pyqtSignal(str, str)` — собственный сигнал виджета из `cl2.py`.
- `Some.on_amount_edited()` — слот проверки ввода и запуска пересчёта.
- `Data.value_changed = pyqtSignal(str, float)` — собственный сигнал модели из `cl1.py`.
- `Some.update_fields()` — слот обновления остальных полей.
- `QPushButton.clicked` подключён к слоту `reset_values()`.

Для предотвращения повторной обработки при программной смене текста используется `blockSignals(True)` и `blockSignals(False)`.
