# Лабораторная работа №1

## Создание графического интерфейса с использованием PyQt5

### Цель работы

Изучить основы создания графического интерфейса на языке Python с использованием библиотеки PyQt5. Научиться создавать окна, размещать элементы управления, обрабатывать нажатия кнопок и отображать изображения.

### Описание программы

В рамках лабораторной работы разработано приложение с графическим интерфейсом, состоящее из основного окна, текстовой надписи и двух кнопок.

**<ins>Функциональные возможности:</ins>**

- При запуске программы открывается главное окно с надписью «Надпись» и двумя кнопками.
- При нажатии на кнопку «Кнопка 1» текстовая надпись заменяется изображением, загруженным из файла image.png.
- При нажатии на кнопку «Кнопка 2» открывается дополнительное окно, форма которого определяется изображением beeee.png с прозрачным фоном.
- Дополнительное окно не имеет стандартной рамки и может быть закрыто нажатием на изображение или клавишей Escape.

### Основные компоненты

| Компонент  | Назначение |
| ------------- | ------------- |
| QApplication  | Управление графическим приложением  |
| QWidget  | Отображение текста и изображений  |
| QLabel  | Создание окон приложения  |
| QPushButton  | Создание кнопок  |
| QPixmap  | Загрузка и отображение изображений  |
| clicked.connect()  | Обработка нажатий кнопок  |

### Вывод

В ходе выполнения лабораторной работы было разработано графическое приложение на языке Python с использованием библиотеки PyQt5. Были изучены основные компоненты графического интерфейса, методы работы с изображениями и механизм сигналов и слотов. Реализованы обработчики нажатий кнопок, позволяющие заменять текст изображением и открывать дополнительное окно с прозрачным фоном.
