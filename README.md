### :pushpin: **Лабораторная работа № 1**

В папке `GUI lab1` лежат следующие файлы:

1. Модуль `main.py` содержит классы `MainWindow` и `PngWindow`, реализующие графический интерфейс приложения с использованием библиотеки PyQt5.

4. Внутри папки есть подробное описание лабораторной работы с демонстрацией работы программы на скриншотах в файле `README.md`.

### :pushpin: **Лабораторная работа № 2**

В папке `GUI_Lab2` лежат следующие файлы:

1. Модуль `main.py` содержит главное окно приложения и обработчики сигналов, реализующие графический интерфейс конвертера валют с использованием библиотеки PyQt5.

3. Модуль `cl2.py` содержит класс поля ввода с пользовательским сигналом, обеспечивающим взаимодействие между компонентами интерфейса.
4. Внутри папки есть подробное описание лабораторной работы с демонстрацией работы программы на скриншотах в файле `README.md`.

### :pushpin: **Лабораторная работа № 3**

В папке `GUI_Lab3` лежат следующие файлы:

1. Модуль `main.py` содержит класс `MainWindow`, реализующий графический интерфейс приложения с меню, кнопками, выпадающим списком и пятью вкладками для отображения результатов SQL-запросов.
2. Модуль `database.py` содержит класс `DatabaseManager`, отвечающий за подключение к базе данных SQLite и закрытие соединения.
3. Модуль `queries.py` содержит SQL-запросы для получения информации о структуре базы данных, её объектах и содержимом таблиц.
4. Модуль `create_demo_db.py` предназначен для создания учебной базы данных SQLite.
5. Файл `demo.db` содержит учебную базу данных со сведениями о студентах, предметах и оценках.
6. Внутри папки есть подробное описание лабораторной работы с демонстрацией работы программы на скриншотах в файле `README.md`.
