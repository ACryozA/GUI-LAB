### Описание программы

Разработано графическое приложение для подключения к базе данных SQLite, выполнения SQL-запросов и отображения полученных результатов в таблицах.
Программа содержит меню управления соединением с базой данных, три кнопки выполнения запросов, выпадающий список выбора таблицы и пять вкладок для отображения результатов.

**Основные функциональные возможности:**

- **Set connection** - выбор файла базы данных через `QFileDialog` и установка соединения.
- **Close connection** - закрытие соединения с базой данных и очистка всех вкладок.
- **Tab1** - автоматический вывод структуры базы данных с помощью запроса `SELECT * FROM sqlite_master`.
- **Tab2** - отображение названий объектов базы данных при нажатии кнопки `bt1`.
- **Tab3** - отображение всех записей выбранной в `QComboBox` таблицы.
- **Tab4** - вывод количества объектов базы данных, сгруппированных по типам, при нажатии кнопки `bt2`.
- **Tab5** - вывод списка пользовательских таблиц и SQL-команд их создания при нажатии кнопки `bt3`.

Для проверки работы приложения используется учебная база данных `demo.db`, содержащая сведения о студентах, учебных предметах и оценках.

### Основные компоненты

- `QMainWindow` - главное окно приложения с меню и элементами управления.
- `QFileDialog.getOpenFileName()` - диалог выбора файла базы данных SQLite.
- `QSqlDatabase` - создание и управление соединением с базой данных.
- `QSqlQuery` - выполнение SQL-запросов к базе данных.
- `QSqlQueryModel` - модель для хранения результатов SQL-запросов.
- `QTableView` - отображение результатов запросов в виде таблиц.
- `QTabWidget` - организация пяти вкладок для отображения различных результатов.
- `QComboBox` - выпадающий список выбора пользовательской таблицы.
- `QPushButton.clicked` - сигнал нажатия кнопки, связанный с соответствующим обработчиком.
- `DatabaseManager` - класс из модуля `database.py`, отвечающий за подключение и отключение базы данных.
- `MainWindow.display_query()` - метод выполнения запроса и отображения результата в выбранной вкладке.

Для получения сведений о структуре базы данных используется системная таблица `sqlite_master`.

При выборе таблицы в выпадающем списке формируется запрос:

```sql
SELECT * FROM "имя_таблицы";
```

Результаты выполнения запросов отображаются в соответствующих вкладках с помощью `QSqlQueryModel` и `QTableView`.

**<ins>5. Выполнение запроса с помощью кнопки bt2</ins>**

При нажатии кнопки `bt2` выполняется запрос для подсчёта количества объектов каждого типа:

```sql

    COUNT(*) AS object_count
FROM sqlite_master
GROUP BY type
ORDER BY type;
```
